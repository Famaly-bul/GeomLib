<h1>Геометрическая библиотека GeomLib</h1
<h2>Описание библиотеки</h2>
  <p>GeomLib — простая Python-библиотека для вычисления площади круга и треугольника. Она также способна определять, является ли треугольник прямоугольным.</p>
  <p>Особенность библиотеки заключается в применении объектно-ориентированного подхода и строгой валидации передаваемых данных.</p>
<h2>Из чего себя представляет проект</h2>
<p>Изначально я подумал,что весь код можно написать из двух функций но тогда большая часть дополнительных заданий не будет выполнена и принялся обдумывать как следует написать код грамотно.</p>
<p> Так же в этом проекте будут представлены:</p>
<ul>
  <li>Легкость добавления других фигур</li>
  <li>Юнит тесты с использованием unittest</li>
  <li>Вычисление площади фигуры без знания типа фигуры</li>
  <li>Проверку на то, является ли треугольник прямоугольным</li>
</ul>
<h2>Требования к выполнению</h2>
<p>Задание:

Напишите на C# или Python библиотеку для поставки внешним клиентам, которая умеет вычислять площадь круга по радиусу и треугольника по трем сторонам. Дополнительно к работоспособности оценим:

- Юнит-тесты

- Легкость добавления других фигур

- Вычисление площади фигуры без знания типа фигуры в compile-time

- Проверку на то, является ли треугольник прямоугольным</p>
